# Factorio Schemes Telegram Bot

Telegram-бот для публикации и поиска пользовательских схем Factorio. Проект реализует каталог с навигацией через inline-клавиатуры и хранением данных в SQLite.

## Возможности

- публикация новой схемы;
- просмотр новых и популярных схем;
- поиск по названию;
- постраничная навигация по результатам;
- просмотр собственных публикаций;
- редактирование и удаление схем;
- добавление комментариев.

## Стек

Python, aiogram 2, asyncio, SQLite.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

В `.env` необходимо указать новый `TELEGRAM_BOT_TOKEN`. Файл с рабочими секретами не должен добавляться в Git.

## Структура

- `bot.py` — команды, состояния пользователя и навигация;
- `dms.py` — выполнение запросов к SQLite;
- `keyboards.py` — клавиатуры Telegram;
- `config.py` — загрузка токена из окружения.

## Статус

Учебный проект сохранён как пример событийного Telegram-приложения. Перед production-использованием необходимы параметризованные SQL-запросы, миграции базы, логирование и автоматические тесты.
